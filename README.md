# yt-playlist-nextcloud-sync
This program syncs your youtube playlist onto your nextcloud filesystem, so you can listen to your youtube music on Amperfy or Subsonic with the Nextcloud Music App

Each downloaded track gets the name of its YouTube playlist written to the album metadata field.

## Installation
This project is a docker based program

Projectstructure
```bash
.
├── .env                # User-configuration
├── docker-compose.yml  
├── Dockerfile
├── main.py
├── requirements.txt
└── README.md
```
